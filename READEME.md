# n8n AI Workflow: PDF Data Extraction

This repository contains an automated workflow built with **n8n** that uses Artificial Intelligence to extract structured information from PDF files and store them automatically.

## 🚀 How it Works
1. **Trigger**: Starts when a new form is submitted.
2. **Document Processing**: Reads the attached PDF file.
3. **AI Analysis**: An AI Agent processes the text to find specific information.
4. **Data Storage**: The extracted data is automatically inserted into a spreadsheet or database.

## 🛠️ Components
- **n8n**: Workflow automation tool.
- **AI Agent**: To understand and analyze the document context.
- **Information Extractor**: To structure the data.
- **Google Sheets / Database**: For final data storage.

## 📥 How to Import
1. Download the `.json` file from this repository.
2. Open your n8n instance.
3. Click on the menu and select **Import from File**.
